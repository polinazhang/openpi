## Data Processing

Mode 1 results
**perturbance**
The result values are the gradient norm $S_v := \|g_v\|_2$ $g_v := \nabla_{h_type} L$. All three types: vision, action, time, needs to be plotted separately.

**cosine: standard 1**
The result values are the cosine similarities from condition-training. Completely ignore condition-inference. Do two things (1) average of all layers (2) only the last layer.


Mode 2 results

**gradient guidance vector**
To derive result values, you should combine the two conditions. Denote the gradient generated by condition-training as v_action, and the gradient generated by condition-inference as v_all, both should be vectors of the same dimensions. Calculate v_vision = v_all - v_action, then calculate the L2 norm and squared L2 norm of v_action, v_vision, and v_all, and report all these values. They should be averaged across datapoints and trajectories evenly but you also need to calculate their std.

You should discard the beta scaling and calculate with the stored npy values. If other files contradict with this command, follow this command.

**cosine: standard 2**
Same idea with gradient guidance vector that we want to look into the difference as well. You should use the meta vector instead of the collasped cosine value for this. Obtain cosine_action, cosine_vision, and cosine_all.
